# Forest Edit Dark 影音編輯 App 重新設計

本專案為中國文化大學資傳系 RWD 網頁／App 作業。
重新設計現有之影音編輯軟體（如 InShot / CapCut），解決原產品介面擁擠、高亮度導致視覺疲勞等問題，並實踐 RWD 跨裝置佈局。

- **原產品對照：** https://play.google.com/store/apps/details?id=com.lemon.lvoverseas
- **Figma 互動原型：** https://www.figma.com/design/B4Yj83Q1N8CgiOCRfcInZh/RWD_%25E8%2594%25A1%25E9%2596%258E%25E4%25BB%25BB_Forest-Edit-Dark%25E5%25BD%25B1%25E9%259F%25B3%25E7%25B7%25A8%25E8%25BC%25AF%25E8%25BB%259F%25E9%25AB%2594?node-id=82-2&t=gSmNiXNrr8YL45AA-0 
- **Pitch 簡報影片：** https://www.youtube.com/watch?v=Tdp_tGDLL0k 

## 核心設計主張
1. 極大化預覽的沉浸式工作台，操作列緊湊化。
2. 導入 Forest Edit Dark 護眼高對比深色系統。
3. RWD 多軌時間軸重新配置，捨棄等比例放大。
